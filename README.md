# ウェディングデュエル 公式ルールブック

結婚式の参列者208人がそのままカードになった、対戦型カードゲームのルールブックです。

- `index.html` … サイト本体（画像もすべて内蔵。これ1つで動きます）
- 検索エンジンには載らない設定（`noindex` / `robots.txt`）を入れています

制作：こうきBOX（X: @koukibox_create）

---

### 公開手順（GitHub Pages）

1. GitHubで新しいリポジトリを作る（名前は推測されにくいものを推奨。例：`wd-rulebook-9x5k`）
2. このフォルダの中身（`index.html` / `robots.txt` / `.nojekyll` / `README.md`）を
   リポジトリの画面にドラッグ＆ドロップしてコミット
3. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
4. 1〜2分待つと `https://ユーザー名.github.io/リポジトリ名/` が発行される
5. そのURLをQRコードにして卓上に置く

### 注意

カードには参列者ご本人のお顔とお名前が載っています。
URLは会場の卓上カードや参加者グループなど、閉じた場所にだけ貼ってください。
